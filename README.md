# بوت التذكير بالمواعيد (Telegram Reminder Bot)

بوت تيليغرام تحدد له أنت (المالك) المواعيد، فيذكّر تلقائيًا **كل من بدأ محادثة
مع البوت** (`/start`) **وكل المجموعات النشطة** بكل موعد:

- 🌙 مساء اليوم السابق للموعد (20:00)
- ☀️ صباح يوم الموعد (08:00)
- ⏳ قبل بداية الموعد بساعة

(كل هذه الأوقات قابلة للتعديل في `config.py`). يدعم المواعيد التي تتكرر كل أسبوع،
ويبقى البث اليدوي متاحًا: أي رسالة ترسلها للبوت في الخاص تصل للجميع.

## 1. إنشاء البوت عبر BotFather

1. افتح محادثة مع [@BotFather](https://t.me/BotFather) في تيليغرام.
2. أرسل `/newbot` واتبع التعليمات (اسم البوت، ثم username ينتهي بـ `bot`).
3. سيعطيك BotFather **توكن** بالشكل: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — احتفظ به.
4. (اختياري لكن مستحب) أرسل `/setprivacy` لـ BotFather، اختر بوتك، ثم اختر `Disable` —
   هذا يسمح للبوت برؤية كل الرسائل في المجموعة عند الحاجة مستقبلاً. غير ضروري
   للبث نفسه لأن البوت يرسل باستخدام صلاحياته كمشرف فقط.
5. احصل على **معرّفك الرقمي (Owner ID)** عبر إرسال أي رسالة لبوت مثل
   [@userinfobot](https://t.me/userinfobot) — سيعطيك رقمًا مثل `987654321`.

## 2. تثبيت المكتبات

يتطلب Python 3.11 أو أحدث (بسبب استخدام `zoneinfo` والأنواع الحديثة).

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## 3. تعديل الإعدادات

1. انسخ `.env.example` إلى ملف جديد اسمه `.env`:

```bash
copy .env.example .env
```

2. افتح `.env` وضع فيه التوكن ومعرّفك:

```
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
OWNER_ID=987654321
```

3. افتح `config.py` وعدّل حسب الحاجة (كل هذا في مكان واحد فقط):
   - `DAY_BEFORE_REMINDER_TIME` — وقت تذكير مساء اليوم السابق (`None` لإلغائه).
   - `MORNING_REMINDER_TIME` — وقت تذكير صباح يوم الموعد (`None` لإلغائه).
   - `MINUTES_BEFORE_REMINDERS` — تذكيرات قبل البداية بالدقائق، مثلاً `[60, 10]`
     = قبل ساعة وقبل 10 دقائق.
   - `ANNOUNCE_TEMPLATE` / `DAY_BEFORE_TEMPLATE` / `MORNING_TEMPLATE` / `BEFORE_TEMPLATE`
     — نصوص الرسائل.

## 4. إضافة البوت لمجموعة

1. أضف البوت (بـ username الذي اخترته) لمجموعة تيليغرام الخاصة بالفوج.
2. اجعله **مشرفًا (Admin)** — على الأقل بصلاحية إرسال الرسائل، حتى يعمل البث.
3. بمجرد إضافته سيُسجَّل تلقائيًا في قاعدة البيانات، وستصلك رسالة تأكيد في الخاص
   من البوت (بشرط أن تكون قد بدأت محادثة معه بـ `/start` أولاً حتى يقدر يراسلك).

## 5. التشغيل

```bash
python main.py
```

سيظهر في الطرفية سطر `البوت جاهز ويعمل.` — هذا يعني أن البوت متصل ويعمل.

### الاستضافة للتشغيل المستمر (24/7)

هذا سكربت `run_polling` عادي يحتاج عملية تعمل باستمرار. الخيارات الشائعة:

- **VPS بسيط** (مثل Hetzner/DigitalOcean/Contabo): شغّله عبر `systemd` service أو
  داخل `screen`/`tmux`، أو استخدم `pm2`/`supervisor` لإعادة التشغيل التلقائي عند الأعطال.
- **Docker**: أنشئ `Dockerfile` بسيط (`FROM python:3.12-slim`، `pip install -r requirements.txt`،
  `CMD ["python", "main.py"]`) وشغّله عبر أي منصة تدعم حاويات طويلة الأمد
  (Railway، Fly.io، VPS مع Docker).
- **تجنّب منصات serverless/تنتهي صلاحية الطلب** (مثل Vercel Functions العادية) لأن
  `run_polling` عملية طويلة الأمد وليست طلب HTTP قصير.

مثال بسيط لـ systemd على VPS (Linux):

```ini
# /etc/systemd/system/course-bot.service
[Unit]
Description=Reminder Telegram Bot
After=network.target

[Service]
WorkingDirectory=/home/youruser/telegram
ExecStart=/home/youruser/telegram/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable course-bot
sudo systemctl start course-bot
```

## 6. الاستخدام اليومي

### للمشتركين (أي شخص)

يكفي أن يفتح البوت ويضغط **Start** — من تلك اللحظة تصله كل التذكيرات.

| الأمر | الوظيفة |
|---|---|
| `/start` | تفعيل التذكيرات |
| `/upcoming` | عرض المواعيد القادمة |
| `/stop` | إيقاف التذكيرات |

### للمالك (في الخاص مع البوت)

| الأمر | الوظيفة |
|---|---|
| `/add` | إضافة موعد جديد خطوة بخطوة (التاريخ، العنوان، التفاصيل، هل يتكرر أسبوعيًا) |
| `/appointments` | المواعيد القادمة بأرقامها وأوقات تذكيراتها |
| `/announce <رقم>` | إعلان موعد للجميع الآن |
| `/delete <رقم>` | حذف موعد |
| `/cancel` | إلغاء إضافة موعد جارية |
| `/subscribers` | عدد المشتركين والمجموعات النشطة |
| `/list_groups` | المجموعات المسجّلة وحالتها |
| `/activate <chat_id>` / `/deactivate <chat_id>` | تفعيل/إيقاف مجموعة |
| أي رسالة نص/صورة/فيديو/مستند | تُبث فورًا لكل المشتركين والمجموعات النشطة |

### مثال: إضافة موعد

```
أنت:  /add
البوت: 🗓 متى الموعد؟
أنت:  الاثنين 20:00          (أو: 15/10 20:00 — غدا 18:30 — اليوم 21:00)
البوت: 📌 ما عنوان الموعد؟
أنت:  جلسة اللايف الأسبوعية
البوت: 📝 أرسل التفاصيل أو /skip
أنت:  https://meet.google.com/xxx-xxxx-xxx
البوت: 🔁 هل يتكرر كل أسبوع؟   [مرة واحدة] [كل أسبوع 🔁]
```

بعدها يعرض البوت أوقات التذكيرات المجدولة، مع زر **📢 أعلنه الآن** إن أردت
إخبار الجميع بالموعد فورًا.

### ملاحظات

- إن أضفت موعدًا لنفس اليوم بعد الساعة 8 صباحًا، لن يُرسل تذكير الصباح متأخرًا —
  استخدم زر الإعلان بدلاً منه.
- الموعد الأسبوعي ينتقل تلقائيًا للأسبوع التالي بعد بدايته، ولا يتوقف حتى تحذفه.
- إن توقف البوت ثم أُعيد تشغيله، لا يضيع شيء: يُرسل أحدث تذكير فاته فقط
  (بدل إغراق الناس بعدة رسائل)، ولا يتكرر أي تذكير أُرسل سابقًا.
- بعد كل تذكير تصلك رسالة تلخّص عدد من وصلهم ومن فشل الإرسال لهم.
- من يحظر البوت يُوقف الإرسال له تلقائيًا.

## ملاحظات أمان وعزل

- لا يوجد أي `forward` بين المجموعات، ولا أي رابط دعوة مشترك يُنشئه البوت.
- كل عملية إرسال لكل مجموعة مستقلة تمامًا (try/except منفصل) — فشل الإرسال
  لمجموعة واحدة لا يوقف البث عن الباقي، ويُسجَّل في السجل (log) بدل تجاهله.
- إن أُزيل البوت من مجموعة، يتم اكتشاف ذلك تلقائيًا (سواء عبر حدث المغادرة أو
  عند فشل إرسال) وتُعطَّل المجموعة تلقائيًا في قاعدة البيانات دون حذف سجلّها.
- ملف `.env` يحوي التوكن ومعرّفك — لا ترفعه لأي مستودع عام (git).
